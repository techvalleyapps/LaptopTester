💻 More Useful Commands
OS:
Run in Command Prompt (CMD) as Administrator — Win + R → cmd → right-click → Run as administrator.
Energy efficiency report (60-second scan, saves to Downloads):
powercfg /energy /output "%USERPROFILE%\Downloads\energy-report.html"
Quick battery level check (%):
wmic PATH Win32_Battery GET EstimatedChargeRemaining
Design capacity in mWh (needs Admin):
wmic /namespace:\\root\wmi PATH BatteryStaticData GET DesignedCapacity
Full charge capacity in mWh (needs Admin):
wmic /namespace:\\root\wmi PATH BatteryFullChargedCapacity GET FullChargedCapacity
Run in Terminal — ⌘ Space → type terminal → Enter.
Full battery report — cycle count, health, condition, capacity:
system_profiler SPPowerDataType
Quick cycle count + capacity (works on Intel & Apple Silicon):
ioreg -l | grep -e CurrentCapacity -e MaxCapacity -e CycleCount -e DesignCapacity
Current battery level & charging status:
pmset -g batt
Open System Information directly to Power section:
open /System/Applications/Utilities/System\ Information.app
Raw Apple Smart Battery data (detailed, Intel Macs):
ioreg -rn AppleSmartBattery | grep -E "Cycle|Capacity|Health|Condition|Temp"
